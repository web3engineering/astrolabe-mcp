# Prompts

Prompts that work well with the Astrolabe MCP server. Copy one, paste it to your agent, and change the details.

Data is up to yesterday and covers about 90 days, so ask about recent periods rather than "today" or "right now".

## First steps

```
Show me pump.fun token launches per day over the last 7 days, and give me a link I can share.
```

```
What databases and tables do you have access to through Astrolabe? Give me a short overview.
```

## Memecoins

```
Which pump.fun tokens migrated to PumpSwap yesterday? Show the top 20 by PumpSwap volume, with a link.
```

```
Compare daily pump.fun launches and migrations over the last 30 days on one chart.
```

```
Build a dashboard about PumpSwap: daily volume, number of traders, and the top pools by volume over the last 14 days.
```

## Wallets

```
Here is a dashboard: https://astrolabe.cartographer.club/dashboards/71
Fork it and change the target to 3x within 6 hours.
```

```
For this wallet <paste a Solana address>, show every pump.fun token it bought in the last 7 days and how each one did after the buy.
```

## Perps and prediction markets

```
Show daily liquidation volume on Hyperliquid over the last 30 days, split by long and short.
```

```
Which Polymarket markets had the most trading volume last week? Top 20, with a link.
```

## RWA

```
Show daily trading volume of tokenized stocks on Solana over the last 30 days, by ticker.
```

## Tips

- Ask for a link when you want a page. A single number comes back as an answer, without a page.
- To change an existing dashboard, paste its link and describe the change. The agent edits a copy, never the original.
- If a query is slow, ask the agent to narrow the date range or add filters.
